跑 · v_run等 · v_wait保险下 v_run = c₁当前 m

银行账本：谁拿到了什么

先到先得（序贯服务）：排在前面的人足额拿到 c₁

—

c₁ = 1 / [λ + (1−λ)·R^(1/γ−1)]，c₂ = c₁·R^(1/γ)

最优存款合同：在两类消费者之间分配资源，使两期边际效用相等。γ 越大，合同越倾向「抹平」两期消费。

claims(m) = λ + m·(1−λ)

提款总需求：早期消费者必取，再加 m 比例的恐慌性提前取款。

v_run(m) = min{ c₁, 1 / claims(m) }

跑的预期收益：能足额兑付时拿 c₁；提款超过资产时，按比例瓜分。

v_wait(m) = (1 − claims·c₁)·R / [(1−m)(1−λ)]

等的预期收益：剩余资产增值后由等待者分享；若 claims·c₁ ≥ 1（资金耗尽），则为 0。

m* = (c₂−c₁)/[c₁(R−1)]，m̄ = (1/c₁−λ)/(1−λ)

m*：跑/等无差异的博弈临界点；m̄：银行资产恰好耗尽的清算临界点。二者含义不同。

保险下：v_run = c₁，v_wait = c₂ > c₁

全额存款保险让跑永远吃亏，挤兑均衡被直接排除，唯一均衡是正常均衡。

v_run / v_wait 是排队位置不确定时的预期人均消费；「银行账本」面板展示先到先得下的实际分配。所有数值与仓库 dd_model.py 完全一致，属于课堂重构，不是 Diamond–Dybvig 原文校准。

政策含义 · 存款保险

打开保险开关：v_wait = c₂ > c₁ 恒成立，挤兑均衡消失——这正是 DD 支持存款保险的核心论证；现实中的保险必须配套资本监管。

m* 与 m̄ 含义不同：前者是「个体跑/等无差异」的博弈临界，后者是「银行资产耗尽」的会计临界。本页为课堂重构，可交互演示，不能替代原论文的严格推导与校准。
