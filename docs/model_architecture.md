# 银行危机与衰退传导模型

本次修订保留 DD，增加融资成本与 IS–LM 的明确联系。论文的问题是：银行危机为什么可能在货币条件之外降低并持续拖累产出。以下是课堂重构，参数和联动接口均非历史估计。

## 核心结构

DD 的银行对应商业银行式存款中介。央行是另加的政策主体。基本 DD 解释期限转换和自我实现的挤兑，没有完整刻画贷款违约与资不抵债，也没有直接推导货币存量或信息资本损毁。

宏观模块设定：

```math
z_t=\rho z_{t-1}+\theta d_t,\qquad s_t=\bar s+\eta z_t
```

`d` 为新增困境，`z` 为未修复的中介损失，`s` 为简化融资成本楔子。`rho` 表示损失延续程度。`s` 不等于 CCI，也不等于 Baa 收益率。

DD 接口：用晚期消费者中提前提款的比例 `m` 计算清算比例 `q(m)=min(c1*(lambda+(1-lambda)*m),1)`，再设初始 `d=chi*max(q(m)-q(0),0)`。此处给定恐慌比例，不求解均衡选择。额外清算到信息损失的映射是外加假设，不冒充 DD 原文结果。DD 的三期与宏观模型期均不直接对应历史月份。

```math
I_t=\bar I-b(i_t-\pi_t^e+s_t),\quad C_t=\bar C+c(Y_t-T_t)
```

```math
Y_t=C_t+I_t+G_t,\qquad M_t/P_t=kY_t-hi_t
```

其中 `0<=c<1`，`b,k,h>0`，`0<=rho<1`，`theta,eta>0`。`i` 是基准名义利率，`pi_e` 是预期通胀；实际 CPI 通胀不能直接替代预期。`M/P` 是实际货币余额，作为外生比较路径。

令 `Omega=1-c+bk/h`、`A=Cbar-cT+Ibar+G`，则

```math
\Omega Y_t=A_t+b\pi_t^e+(b/h)(M_t/P_t)-bs_t,
\qquad \partial Y_t/\partial s_t=-b/\Omega<0.
```

这给出一个条件命题：保持实际货币余额、其他外生支出与预期通胀不变，信用摩擦仍可降低产出；中介损失的缓慢恢复可延长模型响应。该命题不是历史因果估计。

## 情景与参数

`macro_credit_model.py` 以产出基准 100，设 `c=.6,b=20,k=.05,h=10,theta=.05,eta=chi=1`。初始 DD 输入为 `R=2,lambda=.4,gamma=2,m=.4`，接口给出 `d0≈.29117`。这些数值仅为教学设定。

比较四种情景：仅货币变化；同一货币路径加信用损失并较快恢复；同一路径加信用损失并较慢恢复；货币余额不变而仅信用受损。快慢恢复分别取 `rho=.35,.85`，货币缺口路径为 `-.1*.5**t`，其他外生支出和预期通胀缺口为零。程序逐期求解两市场，输出偏差、参数和 CSV。产出指数不是工业生产历史拟合值。

## 有限政策扩展

给定现金兑付 `W`、现金储备 `R_cash`、新增央行借款 `B`、单位清算所得 `ell`，必要清算为 `max(W-R_cash-B,0)/ell`。实际清算受可售资产约束，超出后仍有支付缺口。这只是在给定提款下比较清算，未重新求解挤兑激励。

净资产 `E=R_cash+V-D-B_existing`。新增可偿还借款同时增加现金和负债，因此其他条件不变、兑付前忽略费用时 `Delta E=0`。`V` 为资产经济价值，`D` 为存款。资产已不足偿债时，借款不自动填补资本缺口。算例不意味着资不抵债者现实中必然获得支持。未实现抵押品规则、偿还利息、财政预算或完整救助均衡。

可选的贷款数量约束 `L_supply<=min(D+B+E-R_cash,E/kappa)` 仅适用于正资本、贷款按面值和其他资产固定的简化设定。`kappa` 不是对 1930 年代现代监管规则的假定。**本版未实现该数量约束、借款人净资产反馈或完整金融加速器**；正式加入前还需规定贷款如何限制投资，避免价格与数量渠道重复计算。

## 数据与估计边界

随仓库提供的 CSV 是原聊天附件的原样副本，标签自称来源于 FRED。其数值未在本次逐点在线核验；文件哈希记录在描述结果中。字段为 `date,ip,cpi,baa,dln_ip,inflation`，60 个月，1929-01 至 1933-12。新增程序核对日期连续性、有限数值和对数差分。

该文件缺少货币增长、银行困境与借款人困境；不能直接运行完整回归。INDPRO 不是 GDP，BAA 是收益率水平而非信用利差，CPI 不是货币。可选补充 AAA 构造 BAA−AAA，但公司债利差仍不是银行信贷供给的直接测量。

完整历史回归必须先补齐来源可追溯的变量并对齐样本。使用少量变量和滞后项，在相同样本上比较模型；检查序列性质、时序相关、1933 年特殊月份和样本敏感性。滞后和稳健标准误不消除内生性。当前普通 OLS 标准误及正态近似 p 值不足以完成正式的时序稳健推断。

原模拟回归的生成过程预设金融困境压低产出，其显著性和拟合度不能验证历史信用机制。修订版剔除不可观测的初始滞后值，在共同的 59 期演示样本上运行；不将初始滞后值补零。

## 优先级与局限

| 模块 | 论文用途 | 实现状态 |
|---|---|---|
| DD | 危机脆弱性的微观基础 | 保留 |
| 持续性状态、融资成本、投资与 IS–LM | 回答货币因素之外的产出效应 | 已实现教学情景 |
| 最后贷款人与净资产 | 区分流动性与偿付能力 | 静态教学算例 |
| 资本／贷款数量与借款人净资产 | 进一步讨论约束与反馈 | 可选，未实现 |
| 历史数据 | 背景描述 | 已核对文件内部一致性 |
| 历史渠道识别 | 因果贡献 | 未完成，不声称已检验 |

模型假定短期需求决定产出且中介服务不能被即时替代，未刻画供给、国际金本位、利率下限及完整财政约束。高 `rho` 只展示假设的持续性，不能证明历史恢复缓慢。

与老师确认：课程重点是机制推导还是实际估计；IS–LM 接法是否满足要求；政策扩展应侧重流动性还是资本；若必须估计，是否扩大样本。保留 2008 年为有限机制对照，不另建第二套估计模型。
